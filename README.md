# Quartermaster

A modular, offline-first gaming toolkit hub. Desktop app built with Tauri v2.

## What is this?

One app, multiple games. Each game gets its own module with data lookups, reference tools, and utilities — all cached locally so it works without internet.

## Supported Games

- **Escape from Tarkov** — in development
- **Elite Dangerous** — planned
- **Star Citizen** — planned
- **Minecraft** — planned

## Tech Stack

Tauri v2 · React 19 · TypeScript · Tailwind CSS v4 · Zustand · Dexie.js · SQLite

## Development

```bash
npm install          # install dependencies
npm run tauri dev    # run in development mode
npm run tauri build  # build for production
```

Requires Node.js 20+ and Rust toolchain.
